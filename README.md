# 세아분식
GitHub Pages에서 바로 실행할 수 있는 간단한 분식집 게임입니다.

## 기능
- 손님 주문 선택
- 떡볶이/로제떡볶이 재료 순서대로 클릭
- 튀김 메뉴를 튀김기에 넣고 완성
- 완성 음식 판매 후 돈 누적
- 상점에서 업그레이드 구매
- 돈을 모아 Lv.1~Lv.5 가게 성장
- 가게 이름을 플레이어가 직접 변경
- 진행 상황은 브라우저 localStorage에 자동 저장

## GitHub Pages
1. 이 폴더의 `index.html`, `style.css`, `script.js`를 GitHub 저장소에 업로드
2. Settings → Pages → Deploy from a branch 선택
3. main 브랜치 / root 폴더 선택
4. 생성된 Pages 주소로 접속
